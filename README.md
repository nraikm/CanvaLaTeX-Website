# Canva LaTeX Plugin Website

A simple static website for the Canva LaTeX Plugin.

Production URL: <https://canvalatex-website.vercel.app>

## Pages

- `index.html`
- `terms.html`
- `privacy.html`
- `support.html`

## Local Preview

```sh
npx serve .
```

## Vercel

This project can be deployed as a static site on Vercel. No build command is
required.
